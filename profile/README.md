# 林森课堂 / Listen Class

AI-assisted classroom platform · PC Web、macOS、iOS 与 Agent 工具链。

## Repository Map · 仓库地图

| Repo | Role |
|------|------|
| [**skill**](https://github.com/listen-class/skill) | Cursor Agent Skill |
| [**cli**](https://github.com/listen-class/cli) | CLI source；`./install.sh` 将 `listen` 装到用户 PATH（`~/.local/bin` 等） |
| [**web**](https://github.com/listen-class/web) | PC Web（UX 源） |
| [**mac-app**](https://github.com/listen-class/mac-app) | macOS 桌面端（原 `client`） |
| [**ios-app**](https://github.com/listen-class/ios-app) | iOS（原 `ios`） |
| [**docs**](https://github.com/listen-class/docs) | **仅**设计风格 + 产品文档（PRD / 交互 / 三端 UX / 设计系统） |
| [**agent**](https://github.com/listen-class/agent) | Python Agent（LangGraph / LangChain + YOLO 等媒体工具） |
| [**server**](https://github.com/listen-class/server) | Java 产品服务端 |
| [**test**](https://github.com/listen-class/test) | 验收 / smoke / live-UI（吸收原 `scripts/`） |
| [**platform**](https://github.com/listen-class/platform) | 可选：历史单体对照仓 |

### Not first-class

- **`bin`** — 不是独立仓；由 `cli` 安装 `listen` 到系统 PATH
- **`tools`** — 已废弃（归档/重命名）；请用 `cli` + `test`
