# 林森课堂 / Listen Class

AI-assisted classroom platform · PC Web、macOS、iOS 与 Agent 工具链。

## Repository Map · 仓库地图

| Repo | Role |
|------|------|
| [**skill**](https://github.com/listen-class/skill) | Cursor Agent Skill |
| [**cli**](https://github.com/listen-class/cli) | CLI 源码；构建后安装 `listen` 到系统 PATH（`~/.local/bin` / `/usr/local/bin`） |
| [**test**](https://github.com/listen-class/test) | 验证 / smoke / live-UI 工具（原脚本归宿） |
| [**web**](https://github.com/listen-class/web) | PC Web |
| [**mac-app**](https://github.com/listen-class/mac-app) | macOS 桌面端（原 `client`） |
| [**ios-app**](https://github.com/listen-class/ios-app) | iOS（原 `ios`） |
| [**docs**](https://github.com/listen-class/docs) | 设计规范 + 产品文档（不含脚本） |
| [**agent**](https://github.com/listen-class/agent) | Python Agent（LangGraph / LangChain + YOLO 等媒体工具） |
| [**server**](https://github.com/listen-class/server) | Java 产品服务端 |
| [**platform**](https://github.com/listen-class/platform) | 历史单体对照仓（可选 / legacy） |

> **`tools` 已废弃 / 归档** — 请勿使用。CLI 见 [`cli`](https://github.com/listen-class/cli)；验证与脚本见 [`test`](https://github.com/listen-class/test)。

## Conventions · 约定

- **cli** — 仅 CLI 源码；安装产物是用户 PATH 上的 `listen`，不是项目内 `bin/` 分发，也不是脚本堆积处。
- **test** — 验证、smoke、live-UI 工具的归宿（吸收原分散脚本）。
- **docs** — 仅设计风格与产品文档。
- **tools** — deprecated / archived；不要再用。
